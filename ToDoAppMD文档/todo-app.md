# 待办事项应用 — 功能需求说明书

## 1. 背景与价值

**为什么做**：用户需要一个现代、简洁、易用的待办事项管理工具，类似 Microsoft Todo 的体验，帮助他们高效管理日常任务。

**做成什么样**：一款基于 Electron 的桌面应用，提供流畅的任务管理体验，支持任务分组、截止日期提醒、Markdown 格式，数据完全本地存储。

---

## 2. 范围

### 本次做

- 任务的增删改查（含拖拽排序、Markdown 支持）
- 任务分组管理（创建/删除/自定义颜色图标）
- 截止日期和多级提醒（15分钟/1小时/1天）
- 本地数据持久化（IndexedDB/SQLite）
- 现代简洁的 UI（模仿 Microsoft Todo 风格）

### 本次不做

- 用户账号系统 — 等用户反馈后再决定
- 云端数据同步 — 下一期考虑
- 多端设备同步 — 需要后端支持
- 分享任务/协作功能 — 等用户反馈

## 4. 需求详述

### 4.1 核心流程

1. 用户打开应用 → 看到主任务列表和左侧导航栏
2. 用户输入任务内容 → 按回车添加到列表
3. 用户点击复选框 → 标记任务完成
4. 用户创建分组 → 将任务分配到不同分组
5. 用户设置截止日期 → 系统到期推送提醒

### 4.2 交互规则

- 任务添加支持 Markdown 格式（粗体、斜体、列表等）
- 支持拖拽任务重新排序
- 支持拖拽任务到不同分组
- 删除任务需要二次确认弹窗
- 删除分组时，如果包含任务，显示任务数量警告
- 编辑任务时按 ESC 或点击空白处取消编辑
- 添加任务时输入框为空则不创建任务
- 任务文本长度限制为 200 字符

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 任务必须包含非空文本内容才能创建 |
| BR-002 | 任务列表显示顺序：未完成在上，已完成在下，各自按创建时间倒序 |
| BR-003 | 截止日期必须是今天或之后的日期 |
| BR-004 | 分组名称不能为空，且不能与已有分组重名 |
| BR-005 | 所有数据存储在本地，不上传到任何服务器 |
| BR-006 | 提醒时间在任务到期时触发系统桌面通知 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 应用启动显示主界面
  - **Given** 用户首次打开应用
  - **When** 应用加载完成
  - **Then** 显示空白的任务列表、添加任务输入框、左侧导航栏显示默认分组

- [ ] **AC-002**: 添加新任务
  - **Given** 用户在任务列表页，输入框聚焦
  - **When** 用户输入任务内容并按下回车键
  - **Then** 新任务添加到列表顶部，显示为未完成状态，输入框清空并保持聚焦

- [ ] **AC-003**: 标记任务完成
  - **Given** 列表中存在未完成任务
  - **When** 用户点击任务前的复选框
  - **Then** 任务显示为完成状态（勾选图标、文字删除线），任务统计数字更新

- [ ] **AC-004**: 取消任务完成
  - **Given** 存在已完成任务
  - **When** 用户点击已完成任务的复选框
  - **Then** 任务恢复为未完成状态，删除线消失

- [ ] **AC-005**: 编辑任务内容
  - **Given** 用户双击任务或点击编辑按钮
  - **When** 用户修改任务内容并按下回车键
  - **Then** 任务保存更新后的内容并显示

- [ ] **AC-006**: 删除任务
  - **Given** 用户右键点击或长按任务
  - **When** 用户选择删除并确认弹窗
  - **Then** 任务从列表中移除，显示删除成功提示

- [ ] **AC-007**: 创建新分组
  - **Given** 用户点击"新建分组"按钮
  - **When** 用户输入分组名称、选择颜色和图标并确认
  - **Then** 新分组出现在左侧导航栏，点击可切换到该分组

- [ ] **AC-008**: 移动任务到分组
  - **Given** 用户已添加任务
  - **When** 用户拖拽任务到目标分组或右键选择移动
  - **Then** 任务移动到该分组，在原分组消失，在目标分组出现

- [ ] **AC-009**: 到期提醒触发
  - **Given** 任务设置了截止日期和时间
  - **When** 到达设定的提醒时间
  - **Then** 系统推送桌面通知，显示任务标题和"已到期"信息

- [ ] **AC-010**: 设置多级提醒
  - **Given** 用户在任务详情或编辑模式
  - **When** 点击提醒设置下拉菜单
  - **Then** 显示选项：到期时、提前15分钟、提前1小时、提前1天、自定义时间

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-011**: 空输入不创建任务
  - **Given** 输入框为空或仅包含空格
  - **When** 用户按下回车键
  - **Then** 不创建任务，输入框保持聚焦，不显示错误提示

- [ ] **AC-012**: 取消编辑
  - **Given** 用户正在编辑任务内容
  - **When** 用户按下 ESC 键或点击空白处
  - **Then** 取消编辑，恢复编辑前的任务内容

- [ ] **AC-013**: 取消删除任务
  - **Given** 删除确认弹窗已显示
  - **When** 用户点击"取消"按钮或点击弹窗外部
  - **Then** 任务保持不变，弹窗关闭

- [ ] **AC-014**: 删除非空分组
  - **Given** 用户尝试删除包含任务的分组
  - **When** 用户点击删除分组
  - **Then** 弹出警告"此分组包含 X 个任务，删除后无法恢复"，确认后分组和所有任务一并删除

- [ ] **AC-015**: 应用重启数据保留
  - **Given** 用户已添加任务和分组
  - **When** 用户关闭应用并重新打开
  - **Then** 所有任务和分组完整显示，状态与关闭前一致

- [ ] **AC-016**: 任务文本长度限制
  - **Given** 用户输入任务文本
  - **When** 文本长度超过 200 字符
  - **Then** 输入框显示剩余可输入字数，超出部分无法输入

- [ ] **AC-017**: 全部任务视图
  - **Given** 存在多个分组的任务
  - **When** 用户在"全部任务"视图
  - **Then** 显示所有分组的任务，按分组名称分组显示，每个分组标题下显示对应任务

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-018**: 任务创建规则 ← BR-001
  - **Given** 用户尝试添加任务
  - **When** 任务内容为空
  - **Then** 不创建任务，任务对象必须包含非空文本和创建时间戳

- [ ] **AC-019**: 任务排序规则 ← BR-002
  - **Given** 任务列表包含已完成和未完成的任务
  - **When** 渲染任务列表
  - **Then** 未完成的任务始终显示在已完成任务之上，各自按创建时间倒序排列

- [ ] **AC-020**: 日期选择限制 ← BR-003
  - **Given** 用户正在设置任务截止日期
  - **When** 打开日期选择器
  - **Then** 过去日期显示为禁用状态，无法选择

- [ ] **AC-021**: 分组命名规则 ← BR-004
  - **Given** 用户创建或重命名分组
  - **When** 输入分组名称
  - **Then** 名称为空或与已有分组重名时，显示错误提示并阻止保存

- [ ] **AC-022**: 本地数据存储 ← BR-005
  - **Given** 用户执行任何任务操作
  - **When** 数据发生变化
  - **Then** 数据自动保存到本地存储，不发起任何网络请求

- [ ] **AC-023**: 界面风格规则 ← BR-006
  - **Given** 用户使用应用
  - **When** 浏览和操作任务
  - **Then** 界面呈现现代简洁风格：圆角卡片设计、流畅动画过渡、清晰的信息层级，类似 Microsoft Todo 的视觉体验

### 5.4 主题系统 (Theme System)

- [ ] **AC-024**: 预设主题列表
  - **Given** 用户打开设置菜单中的主题设置
  - **When** 查看主题选项
  - **Then** 显示 3 个预设主题：明亮主题、深色主题、增强莫兰迪，当前主题标记为选中状态

- [ ] **AC-025**: 切换主题
  - **Given** 用户在主题设置中
  - **When** 点击其他主题选项
  - **Then** 应用界面立即切换到新主题的配色方案，包括背景、文字、边框、按钮等所有颜色元素

- [ ] **AC-026**: 主题持久化
  - **Given** 用户切换了主题
  - **When** 关闭应用并重新打开
  - **Then** 应用使用上次选择的主题，界面颜色与关闭前一致

- [ ] **AC-027**: 默认主题
  - **Given** 用户首次打开应用
  - **When** 应用加载完成
  - **Then** 默认使用增强莫兰迪主题，与现有界面风格保持一致

- [ ] **AC-028**: 按钮强调色
  - **Given** 应用处于任意主题下
  - **When** 查看添加按钮、操作按钮等主要交互按钮
  - **Then** 按钮使用当前主题的强调色（accent-color），悬停时颜色加深或变浅

- [ ] **AC-029**: 复选框和选中状态强调色
  - **Given** 应用处于任意主题下
  - **When** 查看任务复选框、选中菜单项、选中状态元素
  - **Then** 使用当前主题的强调色显示选中和激活状态

- [ ] **AC-030**: 链接和高亮边框强调色
  - **Given** 应用处于任意主题下
  - **When** 查看输入框聚焦状态、可拖拽元素高亮、分组选中边框
  - **Then** 边框和高亮效果使用当前主题的强调色变体（通常为主色的浅色版本）
