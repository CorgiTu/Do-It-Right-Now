# Do It Right Now

> 项目正式更名为 **Do It Right Now** —— 即刻行动，始于足下。

---

## 更新日志

### v1.1.0（2026-05-06）—— 重构与进化

#### 底层重构
- **彻底修复了任务勾选状态的持久化逻辑**，解决了数据迁移后的状态死锁问题，任务完成状态从此可靠稳定。

#### UI/UX 进化
- **纯 SVG 定制复选框**：抛弃了原生复选框，采用纯 SVG 组件，视觉风格统一且精致。
- **"灵动"交互动画**：引入基于贝塞尔曲线的交互动画体系，涵盖：
  - 悬浮上浮效果 — 鼠标悬停时卡片轻盈升起
  - Q弹按压反馈 — 点击时带来富有弹性的触感回馈
  - 丝滑划线动效 — 任务完成时划过的弧线流畅自然

#### 架构优化
- **优化了任务状态管理流程**，确保 React 渲染的不可变性和响应速度，为后续功能迭代奠定坚实基础。

### v1.0.0：核心功能构筑完成

v1.0.2（2026-04-29）：

每日任务分组功能实现
- 新增 "Daily" 分组，支持自动每日更新
- 任务自动设置为可重复（每日重复）
- 每日凌晨自动重置未完成状态
- 支持手动指定每日任务功能

拖拽排序动画全面优化（60fps GPU加速）
- 修复拖拽无让位动画、区块断裂、效果生硬问题
- 被拖拽项脱离文档流，轻微放大（scale 1.02）+ 半透明 + 柔和阴影
- 原位置生成透明占位条，维持列表布局高度，不塌陷
- 拖拽过程中完整跟随鼠标，仅使用 transform 实现位移（GPU硬件加速）
- 其他条目平滑让位，自动上下移动，形成自然"挤压让位"效果
- 所有过渡动画 180ms ease-out 曲线，全程 60 帧不掉帧
- 拖拽结束时平滑过渡到目标位置，动画结束后恢复原始样式
- 仅在左侧拖动手柄上按下鼠标时触发拖拽，防止误触点击
- 任务列表和分组列表拖拽逻辑分离，互不干扰

UI 细节修复
- 修复右上角设置小齿轮图标丢失问题
- 优化拖拽浮层（DragOverlay）显示完整任务/分组信息
- 统一所有拖拽组件的动画配置和占位条实现

v1.0.3（2026-05-01）：

任务标签系统
- 新增标签管理功能，支持创建、编辑、删除标签
- 为任务添加多维标签分类，支持最多 10 个标签/任务
- 标签选择器支持搜索已有标签和快速创建新标签
- 8 种预设颜色可选，自定义标签样式
- 标签云视图按使用频率排序展示
- 按标签筛选任务（支持多标签 AND 组合筛选）
- 标签使用计数自动统计
- 删除标签时自动处理关联任务
- 标签数据持久化存储，重启应用数据不丢失
