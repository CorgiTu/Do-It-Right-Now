## 更新日志

### v1.2.0（2026-05-09）—— 风格重塑与系统夯实

#### 视觉重构：极致简约风格
- **色彩系统全面降噪**：主操作按钮从高饱和亮蓝替换为深邃近黑色（`#1A1A1A`），打造沉稳高级的视觉基调。
- **侧边栏重新设计**：移除生硬的垂直分割线，采用浅灰底色（`bg-gray-50/80`）区分层级，视觉更通透。
- **标签样式重构**：放弃大面积高亮色块，改为极浅灰底 + 主题色小圆点标识的克制风格，减少视觉噪音。
- **卡片边框移除**：任务卡片移除显眼灰色边框，改用微弱弥散阴影界定范围，界面更干净。
- **已完成任务降透明度**：已完成任务区块整体降低透明度至 60%，视觉焦点自然让位于未完成任务。
- **任务内容字重增强**：主标题加粗（`font-bold`），任务内容使用 `font-medium`，次级信息（日期、计数）调淡为 `text-gray-400`，拉开清晰层次。

#### Coinbase Dark 主题修复
- **Tailwind 颜色动态化**：将 15 个核心颜色从编译期静态 Hex 改为 CSS 变量引用（`var(--color-*)`），Dark 主题切换即时生效。
- **新增缺失色值**：补充 `hover` 色值，修复 `hover:bg-coinbase-hover` 无效的问题。
- **阴影同步主题化**：阴影色也改为引用 CSS 变量，深色模式下阴影自动适配。

#### 复选框崩溃修复
- **双重调用根因消除**：修复 `toggleTask` 因 `onChange` 直调 + `onToggleComplete` 回调重复调用导致状态相互抵消的 Bug。
- **事件绑定重写**：将 `onChange`/`onClick` 冲突的混乱事件逻辑废弃，统一为父 div 冒泡拦截 + 单一路径触发。

#### 白屏崩溃修复
- **修复 SubtaskList 运行时崩溃**：修正 `useSubtaskStore()` 解构成 `subtasks` 但 Store 实际暴露 `subtaskMap` 导致的 `TypeError`，组件树不再崩溃。
- **Store 缺失方法补充**：为 `subtaskStore` 新增 `updateSubtaskContent` 方法，修复子任务双击编辑功能。
- **参数缺失修复**：修复 `toggleSubtask`/`deleteSubtask`/`addList` 调用中缺失的参数。

#### 全局字体优化
- **跨平台字体栈**：以 `PingFang SC` 为核心构建苹果系统字体栈，Windows 平台自动降级为 `Microsoft YaHei`。

#### 表单与交互细节
- **子任务按钮隐形化**：将子任务输入框旁显眼的蓝色按钮改为极简灰色文字按钮，未 focus 时保持隐形感。
- **输入框质感升级**：子任务输入框增加 focus 白底 + 灰色描边过渡效果。
- **Toast 通知优化**：纯黑底色 + 弥散阴影，信息展示更聚焦。

### v1.1.0（2026-05-06）—— 重构与进化

#### 底层重构
- **彻底修复了任务勾选状态的持久化逻辑**，解决了数据迁移后的状态死锁问题，任务完成状态从此可靠稳定。

#### UI/UX 进化
- **纯 SVG 定制复选框**：抛弃了原生复选框，采用纯 SVG 组件，视觉风格统一且精致。
- **"灵动"交互动画**：引入基于贝塞尔曲线的交互动画体系，涵盖：
  - 悬浮上浮效果 — 鼠标悬停时卡片轻盈升起
  - Q弹按压反馈 — 点击时带来富有弹性的触感回馈
  - 丝滑划线动效 — 任务完成时划过的弧线流畅自然

#### 架构优化
- **优化了任务状态管理流程**，确保 React 渲染的不可变性和响应速度，为后续功能迭代奠定坚实基础。
