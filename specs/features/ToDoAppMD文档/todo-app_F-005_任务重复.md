# F-005: 任务重复/周期性 — 功能需求说明书

## 1. 背景与价值

**为什么做**：用户有很多周期性任务（如"每天写日报"、"每周一开会"、"每月 15 号还信用卡"），每次都需要手动创建，重复劳动效率低。

**做成什么样**：用户可以设置任务周期性重复（每日/每周/每月/每年/自定义），完成任务后自动推进到下一个周期，减少重复操作。

**关联**：[功能演进路线图](./todo-app_功能演进路线图.md) - F-005

---

## 2. 范围

### 本次做

- 任务设置时选择重复频率（每日/每周/每月/每年/自定义）
- 自定义规则支持：星期选择、日期选择、间隔设置（如每隔 N 周/月）
- 完成任务时重置为未完成，推进到下一个周期
- 支持设置重复任务的结束日期或最大重复次数
- 支持例外日期（跳过特定日期，如节假日）

### 本次不做

- 完成任务时自动创建新任务（下一期考虑，本期采用重置模式）
- 重复任务链的历史/未来任务视图（需要更复杂的 UI，等用户反馈后决定）
- 重复任务提醒增强（如连续通知/弹窗，后续优化）

## 4. 需求详述

### 4.1 核心流程

1. 用户创建或编辑任务 → 点击重复设置 → 选择重复频率
2. 用户根据选择的频率设置具体规则（如星期、间隔、日期等）
3. 用户可选设置结束条件（结束日期或最大重复次数）
4. 用户可选添加例外日期列表
5. 用户完成任务 → 系统重置任务为未完成，推进到下一个周期
6. 系统检查是否满足结束条件或当前日期是否为例外日期，决定是否继续重置

### 4.2 交互规则

- 重复设置通过任务编辑模式下的"重复"按钮触发
- 显示重复频率选择面板：每日/每周/每月/每年/自定义
- 选择"每周"时显示星期多选器（周一至周日）
- 选择"每月"时显示日期选择器（1-31 号）
- 选择"自定义"时显示完整自定义面板（频率类型、间隔数字、具体规则）
- 重复任务在任务卡片上显示重复图标和频率描述（如 🔄 每周周一、周三）
- 例外日期通过日历组件选择，支持添加和删除
- 结束日期通过日期选择器设置
- 最大重复次数通过数字输入框设置（两者选一，不能同时设置）

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-F005-001 | 非重复任务不能设置结束条件或例外日期 |
| BR-F005-002 | 自定义重复间隔必须大于 0（如每隔 1 周、每隔 2 月） |
| BR-F005-003 | 每月重复的日期不能超过该月最大天数（如 2 月不能超过 28/29 天） |
| BR-F005-004 | 例外日期不能早于任务创建日期 |
| BR-F005-005 | 结束日期不能早于任务创建日期 |
| BR-F005-006 | 重复任务的截止日期（如有）在每次重置时自动推进到下一个周期 |
| BR-F005-007 | 任务完成时，若当前日期是例外日期，则重置到例外日期之后的下一个有效周期 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-F005-001**: 设置任务重复频率
  - **Given** 用户在创建或编辑任务
  - **When** 用户点击重复设置并选择频率（每日/每周/每月/每年）
  - **Then** 任务保存重复设置，任务卡片显示重复图标和频率描述

- [ ] **AC-F005-002**: 每周重复具体设置
  - **Given** 用户选择了每周重复
  - **When** 用户选择星期一、星期三并保存
  - **Then** 任务设置为每周一、周三重复，卡片显示"🔄 每周周一、周三"

- [ ] **AC-F005-003**: 自定义重复间隔
  - **Given** 用户选择了自定义重复
  - **When** 用户设置"每隔 2 周"并保存
  - **Then** 任务设置为每隔 2 周重复一次

- [ ] **AC-F005-004**: 自定义每月重复日期
  - **Given** 用户选择了自定义重复
  - **When** 用户设置"每月 15 号"并保存
  - **Then** 任务设置为每月 15 号重复

- [ ] **AC-F005-005**: 设置重复结束日期
  - **Given** 任务已设置重复频率
  - **When** 用户设置结束日期为 2026-12-31
  - **Then** 任务在 2026-12-31 之后不再重置

- [ ] **AC-F005-006**: 设置最大重复次数
  - **Given** 任务已设置重复频率
  - **When** 用户设置最大重复次数为 10 次
  - **Then** 任务在第 10 次完成后不再重置

- [ ] **AC-F005-007**: 添加例外日期
  - **Given** 任务已设置重复频率
  - **When** 用户添加 2026-10-01 为例外日期
  - **Then** 任务在 2026-10-01 不重置，自动推进到下一个有效周期

- [ ] **AC-F005-008**: 删除例外日期
  - **Given** 任务已有例外日期列表
  - **When** 用户点击删除某个例外日期
  - **Then** 该日期从例外列表中移除，任务在该日期恢复正常重置

- [ ] **AC-F005-009**: 完成任务并重置
  - **Given** 任务设置了每日重复
  - **When** 用户标记任务完成
  - **Then** 任务重置为未完成状态，截止日期（如有）推进到明天，显示重复图标

- [ ] **AC-F005-010**: 查看重复任务信息
  - **Given** 任务已设置重复
  - **When** 用户查看任务卡片
  - **Then** 任务卡片显示重复图标、频率描述，以及例外日期数量（如有）

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-F005-011**: 结束日期早于创建日期
  - **Given** 任务创建于 2026-05-01
  - **When** 用户尝试设置结束日期为 2026-04-30
  - **Then** 显示错误提示"结束日期不能早于任务创建日期"，阻止保存

- [ ] **AC-F005-012**: 自定义间隔为 0 或负数
  - **Given** 用户在设置自定义重复间隔
  - **When** 用户输入间隔为 0 或负数
  - **Then** 显示错误提示"间隔必须大于 0"，阻止保存

- [ ] **AC-F005-013**: 每月重复日期超出月份范围
  - **Given** 用户设置每月 31 号重复
  - **When** 当前月份为 2 月（只有 28 天）
  - **Then** 任务在该月重置到 28 号（或最后一个有效日期）

- [ ] **AC-F005-014**: 所有星期都未选择
  - **Given** 用户选择了每周重复
  - **When** 用户没有选择任何星期就尝试保存
  - **Then** 显示错误提示"请至少选择一个星期"，阻止保存

- [ ] **AC-F005-015**: 移除重复设置
  - **Given** 任务已设置重复
  - **When** 用户将重复频率设置为"无"
  - **Then** 任务变为非重复任务，清除所有重复相关设置（结束日期、例外日期、重复次数）

- [ ] **AC-F005-016**: 例外日期早于创建日期
  - **Given** 任务创建于 2026-05-01
  - **When** 用户尝试添加 2026-04-30 为例外日期
  - **Then** 显示错误提示"例外日期不能早于任务创建日期"，阻止添加

- [ ] **AC-F005-017**: 同时设置结束日期和最大次数
  - **Given** 任务已设置结束日期
  - **When** 用户尝试设置最大重复次数
  - **Then** 清除已设置的结束日期，只保留最大重复次数（两者只能选其一）

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-F005-018**: 非重复任务无结束条件 ← BR-F005-001
  - **Given** 任务未设置重复
  - **When** 用户尝试设置结束日期或例外日期
  - **Then** 相关设置项禁用或隐藏，无法设置

- [ ] **AC-F005-019**: 自定义间隔必须大于 0 ← BR-F005-002
  - **Given** 用户在设置自定义重复
  - **When** 输入间隔值
  - **Then** 只能输入大于 0 的正整数

- [ ] **AC-F005-020**: 每月日期不超过月份最大天数 ← BR-F005-003
  - **Given** 用户设置每月重复日期
  - **When** 选择的日期超过当前月份最大天数
  - **Then** 重置时自动调整为该月最后一个有效日期

- [ ] **AC-F005-021**: 例外日期不早于创建日期 ← BR-F005-004
  - **Given** 任何重复任务
  - **When** 添加例外日期
  - **Then** 早于任务创建日期的日期不可选择或添加

- [ ] **AC-F005-022**: 结束日期不早于创建日期 ← BR-F005-005
  - **Given** 任何重复任务
  - **When** 设置结束日期
  - **Then** 早于任务创建日期的日期显示为禁用状态

- [ ] **AC-F005-023**: 截止日期随周期推进 ← BR-F005-006
  - **Given** 重复任务设置了截止日期
  - **When** 任务完成并重置
  - **Then** 截止日期自动推进到下一个周期的相同时间

- [ ] **AC-F005-024**: 例外日期自动跳过 ← BR-F005-007
  - **Given** 任务设置了每日重复，且 2026-10-01 为例外日期
  - **When** 用户在 2026-10-01 完成任务
  - **Then** 任务重置到 2026-10-02（下一个有效周期）
