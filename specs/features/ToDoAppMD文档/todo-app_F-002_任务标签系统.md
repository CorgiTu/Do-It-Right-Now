# F-002: 任务标签系统 — 功能需求文档

## 1. 功能概述

**功能名称**：任务标签系统 (Tag System)

**优先级**：P0（高优先级）

**价值主张**：多维度分类任务，超越单一分组限制，支持灵活筛选

**影响范围**：数据模型扩展、新增 UI 组件、状态管理增强

---

## 3. 验收标准

### 3.1 标签管理

- [ ] **AC-TAG-001**: 创建新标签
  - **Given** 用户在任务编辑界面或标签管理面板
  - **When** 输入新标签名称并确认
  - **Then** 标签创建成功，显示在标签列表中，可选择颜色

- [ ] **AC-TAG-002**: 为任务添加标签
  - **Given** 任务处于编辑状态
  - **When** 用户选择已有标签或创建新标签
  - **Then** 标签关联到该任务，任务卡片显示标签徽章

- [ ] **AC-TAG-003**: 从任务移除标签
  - **Given** 任务已关联标签
  - **When** 用户点击标签上的删除按钮
  - **Then** 标签从任务中移除，关联关系删除

- [ ] **AC-TAG-004**: 编辑标签信息
  - **Given** 用户在标签管理面板
  - **When** 修改标签名称或颜色并保存
  - **Then** 所有关联该标签的任务显示更新后的标签信息

### 3.2 标签筛选

- [ ] **AC-TAG-005**: 按单个标签筛选
  - **Given** 左侧导航栏显示标签列表
  - **When** 用户点击某个标签
  - **Then** 主区域仅显示包含该标签的任务

- [ ] **AC-TAG-006**: 按多个标签筛选
  - **Given** 用户已选择一个标签筛选
  - **When** 用户继续点击其他标签
  - **Then** 筛选条件叠加（AND 逻辑），显示同时包含所有选中标签的任务

- [ ] **AC-TAG-007**: 清除标签筛选
  - **Given** 用户正在进行标签筛选
  - **When** 用户点击"全部任务"或清除筛选按钮
  - **Then** 筛选条件清空，显示所有任务

### 3.3 标签云视图

- [ ] **AC-TAG-008**: 标签云显示
  - **Given** 左侧导航栏有标签区域
  - **When** 用户查看标签云
  - **Then** 显示所有已创建的标签，按使用频率排序，字体大小反映使用次数

- [ ] **AC-TAG-009**: 标签使用计数
  - **Given** 标签已创建
  - **When** 查看标签信息
  - **Then** 显示该标签关联的任务数量

### 3.4 标签删除

- [ ] **AC-TAG-010**: 删除空标签
  - **Given** 标签未关联任何任务
  - **When** 用户删除该标签
  - **Then** 标签直接删除，无需确认

- [ ] **AC-TAG-011**: 删除有关联的标签
  - **Given** 标签关联了 N 个任务
  - **When** 用户删除该标签
  - **Then** 弹出确认"此标签关联 X 个任务，删除后这些任务将失去此标签"，确认后删除标签但保留任务

### 3.5 数据持久化

- [ ] **AC-TAG-012**: 标签数据持久化
  - **Given** 用户创建了标签并关联到任务
  - **When** 关闭应用并重新打开
  - **Then** 所有标签和关联关系完整保留

## 4. 业务规则

| 编号 | 规则 |
|------|------|
| BR-TAG-001 | 标签名称不能为空，长度不超过 20 字符 |
| BR-TAG-002 | 标签名称在同一用户下唯一，不区分大小写 |
| BR-TAG-003 | 一个任务最多可关联 10 个标签 |
| BR-TAG-004 | 标签颜色可选，默认提供 8 种预设颜色 |
| BR-TAG-005 | 删除标签不影响任务本身，仅解除关联关系 |

---

## 5. 界面要求

### 5.1 任务卡片标签显示

- 任务卡片右上角显示标签徽章（最多 3 个，超出显示"+N"）
- 标签徽章显示标签颜色背景
- 悬停时显示完整标签名称

### 5.2 标签选择器

- 任务编辑模式下显示标签选择器
- 支持搜索已有标签
- 支持快速创建新标签
- 显示已选标签列表，可点击移除

### 5.3 左侧导航标签区域

- 分组列表下方显示标签区域
- 可折叠/展开
- 显示标签名称和使用计数
- 点击标签进行筛选
