# 待办事项应用 — 交互优化需求说明

> **变更类型**：体验优化  
> **优先级**：P0  
> **创建日期**：2026-04-26  
> **对应收敛标准**：AC-101 ~ AC-120

---

## 1. 背景与价值

**为什么做**：当前交互存在以下问题：
1. 复选框默认完成任务，容易误操作
2. 无法批量选择和管理任务
3. 添加任务方式单一（仅顶部输入框）
4. 缺少快捷编辑入口

**做成什么样**：
- 复选框改为多选功能，配合批量操作
- 任务末尾添加明确的"完成"和"编辑"按钮
- 右下角浮动按钮添加任务，始终显示
- 批量删除前确认，删除后提示

## 4. 需求详述

### 4.1 核心流程

#### 流程 1：选择单个任务
1. 用户点击任务复选框
2. 任务进入选中状态（复选框勾选，任务卡片高亮）
3. 右下角显示删除浮动按钮

#### 流程 2：选择多个任务
1. 用户依次点击多个任务的复选框
2. 所有被点击的任务都进入选中状态
3. 右下角删除按钮显示选中数量（如"删除 (3)"）

#### 流程 3：批量删除任务
1. 用户选中一个或多个任务
2. 点击右下角"删除"浮动按钮
3. 显示确认弹窗："确定要删除 X 个任务吗？"
4. 用户点击"确认"
5. 任务从列表移除
6. 显示成功提示："已删除 X 个任务"
7. 取消所有选中状态

#### 流程 4：添加新任务
1. 用户点击右下角"➕"浮动按钮
2. 弹出添加任务模态框
3. 用户在输入框中输入任务内容
4. 用户按回车或点击"添加"按钮
5. 任务添加到列表顶部
6. 模态框关闭，输入框清空
7. 新任务自动进入选中状态（可选）

#### 流程 5：标记任务完成
1. 用户查看任务卡片
2. 点击任务末尾的"✓"完成按钮
3. 任务标记为完成状态（删除线，移到已完成区域）
4. 复选框保持原状态（如之前选中，仍选中）

#### 流程 6：编辑任务
1. 用户点击任务末尾的"✏️"编辑按钮
2. 任务内容变为可编辑输入框
3. 用户修改内容
4. 用户按回车或点击空白处
5. 保存修改，退出编辑模式

### 4.2 交互规则

- **复选框**：
  - 点击复选框 = 选中/取消选中任务
  - 选中状态：复选框勾选 + 任务卡片背景高亮（`bg-[var(--color-accent-light)]` + 透明度）
  - 支持同时选中多个任务
  - 完成任务也可以被选中

- **任务操作按钮**：
  - 位置：任务卡片右侧或底部操作栏
  - 包含："✓ 完成"按钮、"✏️ 编辑"按钮
  - 显示方式：始终可见（小图标形式）
  - 按钮样式：简洁图标，悬停时显示背景色

- **浮动按钮**：
  - 位置：页面右下角（固定定位，距离底部和右侧各 24px）
  - 默认状态：显示"➕"添加按钮
  - 选中任务时：显示"🗑️ 删除 (X)"按钮（X 为选中数量）
  - 始终显示，不随页面滚动消失
  - 按钮尺寸：直径 56px 圆形
  - 动画：悬停时放大 1.1 倍，点击时缩小 0.95 倍

- **删除确认弹窗**：
  - 标题："确认删除"
  - 内容："确定要删除 X 个任务吗？此操作不可恢复。"
  - 按钮："取消"（次要）、"删除"（危险色）
  - 点击弹窗外部或按 ESC 取消

- **删除成功提示**：
  - 类型：Toast 通知（右下角或顶部）
  - 内容："已删除 X 个任务"
  - 显示时间：3 秒后自动消失
  - 可手动关闭

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-101 | 至少选中一个任务才能显示删除按钮 |
| BR-102 | 删除操作必须经过二次确认 |
| BR-103 | 删除后必须显示成功提示 |
| BR-104 | 任务内容必须非空才能保存 |
| BR-105 | 添加任务时输入框自动聚焦 |
| BR-106 | 删除操作不可撤销（当前版本） |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-101**: 选中单个任务
  - **Given** 任务列表中存在未完成任务
  - **When** 用户点击任务复选框
  - **Then** 复选框显示为勾选状态，任务卡片背景高亮，右下角显示删除浮动按钮

- [ ] **AC-102**: 选中多个任务
  - **Given** 列表中存在多个任务
  - **When** 用户依次点击 3 个不同任务的复选框
  - **Then** 3 个任务都显示为选中状态，删除按钮显示"删除 (3)"

- [ ] **AC-103**: 标记任务完成
  - **Given** 用户查看未完成任务
  - **When** 用户点击任务末尾的"✓"完成按钮
  - **Then** 任务显示删除线，移到已完成区域，复选框保持原状态

- [ ] **AC-104**: 取消任务完成
  - **Given** 存在已完成任务
  - **When** 用户点击已完成任务的"✓"按钮
  - **Then** 任务删除线消失，移回未完成区域

- [ ] **AC-105**: 编辑任务
  - **Given** 用户查看任务列表
  - **When** 用户点击任务末尾的"✏️"编辑按钮
  - **Then** 任务内容变为可编辑输入框，聚焦，显示当前内容

- [ ] **AC-106**: 保存编辑
  - **Given** 用户正在编辑任务
  - **When** 用户修改内容后按回车
  - **Then** 保存新内容，退出编辑模式，显示更新后的文本

- [ ] **AC-107**: 打开添加任务模态框
  - **Given** 用户在任务列表页
  - **When** 用户点击右下角"➕"浮动按钮
  - **Then** 弹出模态框，包含输入框和添加按钮，输入框自动聚焦

- [ ] **AC-108**: 添加新任务
  - **Given** 添加任务模态框已打开
  - **When** 用户输入"测试任务"并按回车
  - **Then** 任务添加到列表顶部，模态框关闭，输入框清空

- [ ] **AC-109**: 关闭添加模态框
  - **Given** 添加任务模态框已打开
  - **When** 用户点击模态框外部或按 ESC
  - **Then** 模态框关闭，不创建任务

- [ ] **AC-110**: 批量删除任务
  - **Given** 用户已选中 3 个任务
  - **When** 用户点击右下角"删除 (3)"按钮，确认弹窗中点击"删除"
  - **Then** 3 个任务从列表移除，显示成功提示

- [ ] **AC-111**: 删除后自动取消选中
  - **Given** 删除操作已完成
  - **When** 任务从列表移除
  - **Then** 所有选中状态取消，删除按钮消失

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-112**: 取消选中任务
  - **Given** 任务已被选中
  - **When** 用户再次点击该任务的复选框
  - **Then** 该任务取消选中，如还有其他选中任务则删除按钮更新数量，否则删除按钮消失

- [ ] **AC-113**: 删除确认 - 取消
  - **Given** 删除确认弹窗已显示
  - **When** 用户点击"取消"或弹窗外部
  - **Then** 弹窗关闭，任务保持不变，选中状态保持

- [ ] **AC-114**: 删除确认 - 空内容
  - **Given** 添加任务模态框已打开
  - **When** 输入框为空或仅空格，用户按回车
  - **Then** 不创建任务，输入框保持聚焦，不显示错误提示

- [ ] **AC-115**: 删除成功提示
  - **Given** 删除操作已确认
  - **When** 任务从数据库移除
  - **Then** 显示 Toast 提示"已删除 X 个任务"，3 秒后自动消失

- [ ] **AC-116**: 编辑时取消
  - **Given** 用户正在编辑任务
  - **When** 用户按 ESC 或点击空白处
  - **Then** 恢复原内容，退出编辑模式，不保存修改

- [ ] **AC-117**: 编辑时输入空内容
  - **Given** 用户正在编辑任务
  - **When** 用户删除所有内容后按回车
  - **Then** 不保存，保持编辑状态，不显示错误提示

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-118**: 复选框选中规则 ← BR-101
  - **Given** 没有任务被选中
  - **When** 用户未选择任何任务
  - **Then** 右下角删除按钮不显示

- [ ] **AC-119**: 删除确认规则 ← BR-102
  - **Given** 用户点击删除按钮
  - **When** 删除确认弹窗未显示
  - **Then** 必须先显示确认弹窗，用户确认后才能真正删除

- [ ] **AC-120**: 删除提示规则 ← BR-103
  - **Given** 用户确认删除操作
  - **When** 删除完成后
  - **Then** 必须显示成功提示，包含删除的任务数量

## 6. UI/UX 要求

### 6.1 视觉设计

**复选框选中状态**：
- 背景：`bg-[var(--color-accent-light)]` + `bg-opacity-40`
- 边框：`border-[var(--color-accent)]`
- 过渡动画：`transition-all duration-200`

**任务操作按钮**：
- 图标尺寸：16px × 16px
- 按钮间距：8px
- 悬停效果：`hover:bg-[var(--color-hover)]`
- 完成按钮颜色：`text-[var(--color-accent)]`
- 编辑按钮颜色：`text-[var(--color-text-light)]`

**浮动按钮**：
- 尺寸：56px × 56px（圆形）
- 位置：`fixed bottom-6 right-6`
- 背景：`bg-[var(--color-accent)]`
- 悬停：`hover:bg-[var(--color-accent-hover)]` + `transform hover:scale-110`
- 点击：`active:scale-95`
- 阴影：`shadow-lg`
- 图标：白色，24px

**添加任务模态框**：
- 尺寸：最大宽度 480px，居中显示
- 背景：`bg-[var(--color-bg)]`
- 遮罩：`bg-black bg-opacity-30`
- 动画：`animate-fade-in`, `animate-slide-up`
- 输入框：全宽，与现有 TaskInput 样式一致

**Toast 提示**：
- 位置：右下角或顶部居中
- 背景：`bg-[var(--color-text)]` + `text-white`
- 圆角：8px
- 内边距：12px 24px
- 动画：滑入/淡出

### 6.2 交互细节

**浮动按钮状态机**：
```
默认状态 → 显示"➕"
  ↓ (点击)
打开模态框
  ↓ (关闭模态框)
默认状态

默认状态 → 显示"➕"
  ↓ (选中 1 个任务)
显示"🗑️ 删除 (1)"
  ↓ (选中更多任务)
显示"🗑️ 删除 (X)"
  ↓ (取消所有选中)
显示"➕"
```

**任务卡片布局**：
```

│ ☐  任务内容                    [✓] [✏️]    │
│    创建时间  截止日期  提醒                 │
└─────────────────────────────────────────────┘
```
