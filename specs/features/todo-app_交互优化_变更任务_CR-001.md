## 详细变更内容

### 变更 1: TaskListAllView 支持多选和完成切换

**问题**: TaskListAllView 直接渲染 TaskItem 但没有传递必要的 props

**修改**:
```tsx
// TaskListAllView.tsx
import { useTaskStore } from '../store/taskStore'

// 在组件中
const { toggleTask, selectedTaskIds } = useTaskStore()
const isSelected = selectedTaskIds.includes(task.id)

// 渲染 TaskItem 时
<TaskItem 
  task={task} 
  isSelected={isSelected}
  onToggleComplete={() => toggleTask(task.id)}
/>
```

### 变更 2: DueDatePicker 支持时分选择

**当前**: 只能选择日期
**修改后**: 选择日期后可以设置具体的小时和分钟

**交互流程**:
1. 用户点击日期选择器
2. 显示日历选择日期
3. 选择日期后，弹出时分选择器
4. 用户选择小时 (0-23) 和分钟 (0-59)
5. 确认后保存完整的日期时间

**UI 示意**:
```
📅 12 月 26 日 14:30
  ↓ 点击
[日历]
  ↓ 选择日期
[时：14] [分：30]
  ↓ 确认
保存：2024-12-26T14:30:00
```

### 变更 3: 浮动按钮样式优化

**当前**: `🗑️ 删除 (3)`
**修改后**: `删除`（字体小一号，无图标，无数量）

**CSS 调整**:
```tsx
// 移除图标，字体小一号，不显示数量
<span className="text-sm font-medium">删除</span>
```

## 新增验收标准

### AC-121: 全部任务界面支持多选
- **Given** 用户在全部任务界面查看任务列表
- **When** 用户点击任务的复选框
- **Then** 复选框显示选中状态，任务卡片高亮，右下角显示删除按钮

### AC-122: 日期选择器支持时分设置
- **Given** 用户点击任务的日期选择器
- **When** 用户选择日期后
- **Then** 可以进一步选择小时和分钟，保存后显示格式为"MM 月 DD 日 HH:mm"

### AC-123: 浮动按钮简洁显示
- **Given** 用户选中了多个任务
- **When** 查看右下角浮动按钮
- **Then** 按钮显示"删除"二字，无图标，无数量，字体适中
