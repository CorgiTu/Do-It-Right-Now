# 摄影策划知识库系统 — 产品需求说明书 (PRD)

## 1. 背景与价值
摄影师在每次拍摄前都需要做策划，收集大量散落在各平台（小红书、抖音、B站等）的信息。
本项目旨在打造一个单用户 Web 应用，支持上传图片或粘贴链接，系统自动绕过防爬虫机制抓取原帖，利用 AI 多模态大模型分析图文，生成 5 大维度的结构化策划案素材，并支持本地图片备份和 HTML 策划案导出。

## 2. 核心功能范围 (MVP)
- **多平台抓取**：支持小红书（带预登录机制）、抖音等链接提取。
- **长图智能解析**：上传小布记忆长图自动识别二维码溯源。
- **多模态 AI 分析**：基于智谱视觉模型，从“场景、光线、造型、构图、色彩”生成结构化数据。
- **图片本地备份**：提取动态渲染的图片，支持一键下载至本地脱机使用。
- **知识库管理**：瀑布流展示，支持批量上传、自动分类、自定义标签及二次编辑。
- **策划案生成引擎**：根据拍摄主题，优先使用本地备份图片，生成并导出 5 大板块的 HTML 策划案。

## 3. 验收标准 (Acceptance Criteria)

### 3.1 导入与抓取
- [ ] **AC-001**: 上传包含二维码的长图片，系统能自动识别并解码获取原帖 URL。
- [ ] **AC-002**: 无二维码图片上传时，系统降级提供链接输入框，且支持仅对图片做纯 AI 分析。
- [ ] **AC-003**: 粘贴小红书/抖音等链接，系统能自动调用 Playwright 抓取标题、正文、标签。
- [ ] **AC-004**: 支持小红书预登录：提供登录入口，保存 Cookie 以绕过反爬登录墙。

### 3.2 AI 分析与结构化
- [ ] **AC-005**: 提取到的图文信息发给视觉大模型，能稳定返回包含 5 大维度的 JSON 数据。
- [ ] **AC-006**: 图片 URL 提取时过滤掉头像、Icon，只保留原帖高清图。
- [ ] **AC-007**: AI 分析失败或超时时，保留抓取到的基础数据，不中断整体流程。

### 3.3 图片备份与管理
- [ ] **AC-008**: 抓取或上传的图片支持“一键下载备份”，保存到服务器本地目录。
- [ ] **AC-009**: 知识库列表和预览页面，图片旁边展示“下载/移除”状态控制按钮。
- [ ] **AC-010**: 本地备份移除后，系统恢复使用网络原图 URL。

### 3.4 预览、保存与批量操作
- [ ] **AC-011**: AI 分析完成后进入预览模式，用户可修改分类、调整标签并确认保存。
- [ ] **AC-012**: 支持批量上传图片，后台并发处理，前端展示独立进度条，支持批量确认入库。
- [ ] **AC-013**: 每条内容入库必须包含至少一个分类，原帖链接需作为溯源信息固定展示。

### 3.5 知识库展示与二次编辑
- [ ] **AC-014**: 知识库首页以瀑布流展示卡片，包含封面图、结构化摘要和标签。
- [ ] **AC-015**: 支持对已入库的条目进行二次编辑（修改文字内容、更换分类）。
- [ ] **AC-016**: 支持多选知识库条目，进行批量的分类变更和标签追加。

### 3.6 策划案生成与导出
- [ ] **AC-017**: 输入主题词，系统检索关联知识条目，生成包含 5 大板块的策划案。
- [ ] **AC-018**: 策划案生成时，优先使用本地备份的图片作为上下文输入和参考样片。
- [ ] **AC-019**: 若某板块知识库内容不足，系统弹窗提示用户确认后，半自动调用联网搜索补全。
- [ ] **AC-020**: 生成的策划案支持一键导出为内嵌 base64 图片的独立 HTML 文件。
