# F-007: 任务详情侧边栏 — 功能需求说明书

## 1. 背景与价值

**为什么做**：现有任务编辑方式（弹窗/行内编辑）会遮挡任务列表，用户编辑任务时需要频繁切换视图，体验不够专注和流畅。

**做成什么样**：点击任务后从右侧滑出详情侧边栏，用户可以在侧边栏中完成所有编辑操作（内容、日期、标签、子任务、备注），同时保持任务列表可见，提供更专注的编辑体验。

## 2. 范围

### 本次做

- 点击任务展开右侧滑出式详情侧边栏
- 侧边栏任务编辑区（内容编辑、保存、取消）
- 侧边栏日期设置（截止日期、提醒时间）
- 侧边栏标签管理（添加、删除标签）
- 侧边栏子任务管理（已有子任务功能的侧边栏集成）
- 侧边栏备注编辑区
- 任务时间线展示（创建、编辑、完成等关键操作记录）
- 时间线数据持久化（独立时间线表）
- 侧边栏关闭（点击外部区域、ESC键、关闭按钮）
- 侧边栏状态与任务列表同步（编辑后实时更新列表）

### 本次不做

- 侧边栏宽度拖拽调整 — 等用户反馈后再决定
- 相关任务推荐 — 算法复杂度较高，后期考虑
- 任务历史记录编辑/删除 — 时间线只读展示
- 侧边栏多任务切换 — 一次只编辑一个任务

## 4. 需求详述

### 4.1 核心流程

1. 用户在任务列表中点击任务 → 右侧滑出详情侧边栏
2. 用户在侧边栏中编辑任务（内容、日期、标签、子任务、备注）
3. 用户关闭侧边栏（点击外部/ESC/关闭按钮）→ 侧边栏收起，列表实时更新

### 4.2 交互规则

- 点击任务展开侧边栏，同时只能有一个侧边栏打开
- 打开侧边栏时，任务列表中对应的任务项显示选中高亮状态
- 侧边栏打开后，点击侧边栏外部区域（任务列表）关闭侧边栏
- 按 ESC 键关闭侧边栏
- 侧边栏顶部显示关闭按钮（X图标）
- 侧边栏内容编辑后点击"保存"按钮或自动保存（失焦时）
- 编辑内容时提供"取消"按钮，点击后恢复编辑前的内容并关闭侧边栏
- 侧边栏打开时，任务列表中该任务的内容变更实时更新
- 删除任务时，关闭侧边栏并显示删除成功提示
- 子任务管理复用已有子任务组件，在侧边栏中展示
- 时间线为只读展示，用户无法编辑或删除时间线记录

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 任务编辑后必须保存到数据库，且更新时间线 |
| BR-002 | 时间线记录所有关键操作：创建、内容编辑、完成状态变更、日期变更、标签变更、删除 |
| BR-003 | 每条时间线记录包含：操作类型、操作时间、操作前后的值（如适用） |
| BR-004 | 时间线按操作时间倒序展示（最新的在最上面） |
| BR-005 | 侧边栏打开时，如果任务已被删除，关闭侧边栏并提示"任务已不存在" |
| BR-006 | 任务内容编辑遵循 200 字符限制（与现有规则一致） |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 点击任务展开侧边栏
  - **Given** 用户在任务列表页，列表中存在任务
  - **When** 用户点击某个任务
  - **Then** 从右侧滑出任务详情侧边栏，显示该任务的完整信息（内容、日期、标签、子任务、备注、时间线）

- [ ] **AC-002**: 侧边栏显示任务基本信息
  - **Given** 侧边栏已打开
  - **When** 查看侧边栏内容
  - **Then** 显示任务内容编辑框、截止日期、提醒时间、标签列表、子任务列表、备注编辑框、时间线

- [ ] **AC-003**: 侧边栏任务高亮同步
  - **Given** 侧边栏已打开
  - **When** 查看任务列表
  - **Then** 当前编辑的任务在列表中显示选中高亮状态

- [ ] **AC-004**: 编辑任务内容并保存
  - **Given** 侧边栏已打开，用户在编辑任务内容
  - **When** 用户修改任务内容并点击"保存"按钮
  - **Then** 任务内容更新，任务列表同步显示新内容，时间线新增一条"内容编辑"记录

- [ ] **AC-005**: 编辑任务内容自动保存
  - **Given** 侧边栏已打开，用户在编辑任务内容
  - **When** 用户修改任务内容后，编辑框失去焦点
  - **Then** 任务内容自动保存，任务列表同步更新，时间线新增一条"内容编辑"记录

- [ ] **AC-006**: 取消编辑任务
  - **Given** 侧边栏已打开，用户正在编辑任务内容
  - **When** 用户点击"取消"按钮
  - **Then** 恢复编辑前的任务内容，关闭侧边栏，不更新时间线

- [ ] **AC-007**: 设置任务截止日期
  - **Given** 侧边栏已打开
  - **When** 用户在侧边栏中选择截止日期并确认
  - **Then** 任务截止日期更新，任务列表同步显示，时间线新增一条"日期变更"记录

- [ ] **AC-008**: 设置任务提醒时间
  - **Given** 侧边栏已打开
  - **When** 用户在侧边栏中选择提醒时间并确认
  - **Then** 任务提醒时间更新，时间线新增一条"日期变更"记录

- [ ] **AC-009**: 添加任务标签
  - **Given** 侧边栏已打开
  - **When** 用户在侧边栏中添加新标签
  - **Then** 标签显示在标签列表中，任务列表同步显示标签徽章，时间线新增一条"标签变更"记录

- [ ] **AC-010**: 删除任务标签
  - **Given** 侧边栏已打开，任务已有标签
  - **When** 用户在侧边栏中删除某个标签
  - **Then** 标签从标签列表中移除，任务列表同步更新，时间线新增一条"标签变更"记录

- [ ] **AC-011**: 查看任务时间线
  - **Given** 侧边栏已打开，任务有时间线记录
  - **When** 查看侧边栏时间线区域
  - **Then** 按时间倒序展示所有操作记录，每条记录显示操作类型、操作时间、操作详情

- [ ] **AC-012**: 时间线记录关键操作
  - **Given** 用户对任务执行了关键操作（创建、编辑、完成、日期变更、标签变更）
  - **When** 操作完成
  - **Then** 时间线自动新增一条记录，包含操作类型、操作时间、操作前后的值

- [ ] **AC-013**: 点击外部区域关闭侧边栏
  - **Given** 侧边栏已打开
  - **When** 用户点击侧边栏外部区域（任务列表）
  - **Then** 侧边栏收起，任务列表保持当前状态

- [ ] **AC-014**: 按ESC键关闭侧边栏
  - **Given** 侧边栏已打开，焦点在侧边栏内
  - **When** 用户按下 ESC 键
  - **Then** 侧边栏收起，焦点回到任务列表

- [ ] **AC-015**: 点击关闭按钮关闭侧边栏
  - **Given** 侧边栏已打开
  - **When** 用户点击侧边栏顶部的关闭按钮（X图标）
  - **Then** 侧边栏收起

- [ ] **AC-016**: 删除任务
  - **Given** 侧边栏已打开
  - **When** 用户在侧边栏中点击删除任务并确认
  - **Then** 任务从列表中移除，侧边栏关闭，显示删除成功提示，时间线新增一条"删除"记录

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-017**: 重复点击同一任务
  - **Given** 侧边栏已打开，显示任务A的详情
  - **When** 用户再次点击任务A
  - **Then** 侧边栏保持打开状态，不触发重新加载

- [ ] **AC-018**: 点击其他任务切换
  - **Given** 侧边栏已打开，显示任务A的详情
  - **When** 用户点击任务B
  - **Then** 侧边栏内容切换为任务B的详情，任务列表高亮切换为任务B

- [ ] **AC-019**: 任务已被删除时打开侧边栏
  - **Given** 侧边栏已打开，显示任务A的详情
  - **When** 任务A在其他地方被删除
  - **Then** 侧边栏关闭，显示提示"任务已不存在"，任务列表刷新

- [ ] **AC-020**: 编辑空内容
  - **Given** 侧边栏已打开，用户清空任务内容
  - **When** 用户尝试保存
  - **Then** 显示错误提示"任务内容不能为空"，不保存，不更新时间线

- [ ] **AC-021**: 编辑内容超过字符限制
  - **Given** 侧边栏已打开，用户编辑任务内容
  - **When** 任务内容超过 200 字符
  - **Then** 输入框显示剩余可输入字数，超出部分无法输入

- [ ] **AC-022**: 侧边栏打开时应用刷新
  - **Given** 侧边栏已打开
  - **When** 用户刷新应用
  - **Then** 应用加载完成后，侧边栏关闭，显示任务列表

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-023**: 时间线数据持久化 ← BR-001
  - **Given** 用户对任务执行了关键操作
  - **When** 操作完成且数据保存到数据库
  - **Then** 时间线记录同时保存到独立的时间线数据表

- [ ] **AC-024**: 时间线记录完整性 ← BR-002, BR-003
  - **Given** 任务存在时间线记录
  - **When** 查看时间线
  - **Then** 每条记录包含操作类型、操作时间、操作前后的值（如适用）

- [ ] **AC-025**: 时间线排序规则 ← BR-004
  - **Given** 任务有多条时间线记录
  - **When** 查看时间线
  - **Then** 记录按操作时间倒序展示（最新的在最上面）

- [ ] **AC-026**: 任务内容字符限制 ← BR-006
  - **Given** 用户在侧边栏编辑任务内容
  - **When** 输入内容
  - **Then** 内容长度限制为 200 字符，超出部分无法输入
